# Python Coding Exercises

This repository contains a collection of Python programming exercises and solutions, primarily focused on basic concepts and problem-solving.

## Contents

- **Python_Basics_.ipynb**: A Jupyter notebook containing numerous Python questions and answers covering:
  - Conditional Statements
  - Loops
  - Functions
  - And more...

## How to use

You can open the `.ipynb` file using Jupyter Notebook, JupyterLab, or VS Code to explore the questions and run the code cells.
